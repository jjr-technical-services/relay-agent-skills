# Relay Skills

63 native workflows help you research, plan, design, write, analyze, and deliver useful work. Start with `get-started-with-relay` or ask for a concrete task. The bundled workflows do not require a Relay account.

Use the [workflow index](skills/get-started-with-relay/references/workflows.md) to explore research and positioning, marketing and sales, product and design, finance and operations, nonprofit fundraising, engineering, and QA.

The optional OAuth connection to `https://relay.builtbyrose.co/mcp` adds authorized workspace assets and governed catalog routing. Remote tool inputs are sent to Relay; installing native files does not grant access to private organizations or authorize external actions.

Some workflows use browser, research, development, or connected-data tools supplied by your host. The selected workflow identifies required inputs and limitations; it must not invent tool access or claim unperformed actions.

Each bundled skill includes its license and supporting files. Native package checks, remote behavioral qualification, publication, provider review, and directory availability are distinct. Refer to the repository release and provider portals for current publication status.
