# Document layout and leadership summary

Use this order. The leadership summary appears first but is written last.

## Leadership summary (one page)

- **Headline**: one sentence on how communications did against its goals this month.
- **Goal status**: each goal with result and status (on track, behind, ahead, not yet
  measurable).
- **Key results**: three to five plain-language bullets with numbers. Rates in
  percentage points of change; counts with raw values.
- **What we learned**: one or two insights, each marked finding or hypothesis.
- **Caveat that matters**: the one measurement limit leadership should know (for
  example "email opens are directional only this month; clicks were flat").
- **Next month**: the top three actions.
- **Decision or support needed**: or "None this month".

Plain language, no hype, no adjectives such as record-breaking or explosive. Every
number in the summary must appear in the body.

## Body

1. Goals and status table.
2. Metric definitions table.
3. Results by channel, one table each: email, each social platform, website, events
   and registrations, giving (communications view).
4. Content-level insights.
5. Attribution caveats.
6. Next month.
7. Data notes: sources and export dates, definition changes, assumptions, TBD items,
   privacy threshold used.

## Cadence and ownership

- Export data on the same day each month and record export dates.
- Keep a definitions log; when a definition changes, note it in the first edition after
  the change and, where possible, restate the previous period.
- A monthly automation may assemble the exports; this skill supplies the definitions,
  analysis, and writing.
